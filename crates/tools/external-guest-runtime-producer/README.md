# External guest runtime producer

This source-product command is published in the source bundle but not yet installed. Its signed Tool
captures the declaring Bundle's signed owner executable into the exact
`/ryeos/realizations/guest-owner-input` file realization. The command takes
the empty object as input and names no controller: the placing controller's
public key travels in the occurrence assignment it signs, so one product serves
any controller. The Tool provides a canonical signed owner profile and a
retained private project workspace. The command never
reads an installed Bundle path,
provider credential, or provider API. It creates
`products/external-guest-owner-runtime` once and reports its observed content
manifest and owner executable digests.

The source bundles still need installation, product capture and
independent provider snapshot qualification. A successful command or captured
product does not authorize allocation or activation; the snapshot must
separately prove it restored this exact runtime.
